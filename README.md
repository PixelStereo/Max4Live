# PixelStereo tools

Small tools of Pixel Stereo, each in its folder, each with its whole history (its commits, authors and dates, rewritten into its folder).
They were separate repositories:

| Folder | What | Was |
|---|---|---|
| [`dbap4totalmix`](dbap4totalmix) | A remote control for TotalMix (RME sound cards) | PixelStereo/dbap4totalmix |
| [`osc4live`](osc4live) | Max for Live devices | PixelStereo/osc4live |
| [`sound2osc`](sound2osc) | Sound to OSC | PixelStereo/sound2osc |
| [`millumin-trigger-M4L`](millumin-trigger-M4L) | Millumin trigger, Max for Live | PixelStereo/millumin-trigger-M4L |
| [`Ableton-Scene-Trigger-M4L`](Ableton-Scene-Trigger-M4L) | Ableton scene trigger, Max for Live | PixelStereo/Ableton-Scene-Trigger-M4L |
| [`Eos-Cue-Trigger-M4L`](Eos-Cue-Trigger-M4L) | Eos cue trigger, Max for Live | PixelStereo/Eos-Cue-Trigger-M4L |
| [`Eos-Cue-Trigger-Millumin`](Eos-Cue-Trigger-Millumin) | Eos cue trigger for Millumin | PixelStereo/Eos-Cue-Trigger-Millumin |

`git log -- <folder>` shows a tool's history. Their tags are prefixed by their folder (`dbap4totalmix/0.1.2`), and the branch
`Eos-Cue-Trigger-Millumin/wip/cplm-edit` is kept.
